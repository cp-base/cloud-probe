# CLOUD / PROBE — 全体模型 v0.3の案内

2026-11-07。今後育てていく土台の最初の版です。
探索・戦闘・成長・施設・交易・派遣・保存が、同じゲームの中で動きます。

## 開き方

リポジトリをダウンロードまたはcloneし、Godotのプロジェクト一覧から [godot-foundation/project.godot](../../godot-foundation/project.godot) を読み込み、F5でゲーム全体を実行してください。

検証に使ったGodotは4.7.2です。追加の素材・プラグイン・オンライン接続は不要です。旧`godot/`は比較版です。共有ソースはプレイ進行を含まないため、最初は資金0・改修なしから始まります。

## 最初の遊び方

1. 「準備・施設」タブの「選んだ施設から出発」を押す。
2. 光へ近づく。最初は近い光の方を向いて出発します。「自動前進」なら押し続けずに進めます。
3. 光は近づけば自動回収。敵が射程に入れば自動砲撃し、接敵すると近接へ切り替わります。
4. 近くの施設や特別な信号は「アクセス」またはEで開く。機能は施設によって違います。
5. 燃料切れ・耐久切れで出発施設へ戻ったら、得た資金で改修し、もう一度出発する。

最初から10000へ届く性能にはしていません。補給なしの航続は初期250で、速度も旧模型の18から6へ落としました。
v0.3では起点近くに敵を1体追加しました。以前の版の保存を持っている場合は引き継ぎ、追加敵は次の出発から現れます。途中保存を再開した場合、その探索の敵を急に追加・再配置することはありません。

## 今回変えた見た目と敵

格子床と人間の目線の高さを外し、光と敵が床なしの空間に漂う表示にしました。
敵の戦闘タイプは4種類のままで、別に「待機／巡回」の個体差があります。名前の横でも確認できます。
待機個体は近づくと動き出し、巡回個体は付近をゆっくり往復します。どちらも近づけば追跡・攻撃します。
通常生成の配分は維持しています。起点の追加1体は待機個体で、毎回の戦闘タイプは抽選です。

## 操作

| 操作 | キー・ボタン |
|---|---|
| 前進・後退 | W/S、↑↓、画面の前後ボタン |
| 左右へ旋回 | A/D、←→、画面の旋回ボタン |
| 押し続けずに前進 | 自動前進ボタン。後退・停止・画面を開くと解除 |
| 近くへアクセス | Eまたは左上の施設名・アクセスボタン |
| 地図・地点メモ | Mまたは「地図・記録」 |
| 一時停止・再開 | Spaceまたは「一時停止／再開」 |
| パネルを閉じる | Escまたは「閉じる」 |
| 保存 | 自動保存のほか「保存」。通常終了でも保存 |

画面の外へ切り替えた時は一時停止します。航行中の保存を再開した時も、まず「再開」を押してください。

## 施設でできること

- 補給・修理。今回は無料の仮仕様です。
- 航続・推進・戦闘・探知の改修、遠距離と近接の装備選び。
- 候補地への建設。建てた施設は次の探索にも残ります。
- 出発登録の機能がある施設から、次の出発地点を選択。
- 交易品1種類の購入・運搬・売却。初期の積載上限は3です。
- 調査担当1枠へ3Cで依頼。航行中の90秒で未知の施設1か所の情報が届き、派遣機能のある施設で受領できます。

地図の地点メモは追加・削除できます。メモを消しても施設そのものは消えません。
地図から施設を選ぶと、その施設へ表示上の目標を切り替えられます。自動操縦ではありません。

## 保存と、まだ決めていないこと

進行は本体の `.local/campaign.json` に保存します。直前の保存は `.bak` です。
資金・改修・装備・施設・荷物・派遣・記録だけでなく、現在地、敵の耐久、回収済みの光、飛翔中の攻撃も保存します。
旧模型の保存を自動移行する処理は入れていません。

見た目は暫定の3D表示です。世界の仕組みは平面の座標で持っています。
敵の見た目、世界観、画像素材、アイテム生成・ドロップはまだ確定していません。
「設定」の追加発光は初期OFFで、光っぽいシンボル自体が見える描画にしています。

まず全体のつながりが動くところまで作った版です。10000への通常攻略、全域の密度・経済・逃げやすさ・長期バランスはこれから試します。
