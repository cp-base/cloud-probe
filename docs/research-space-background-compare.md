# CLOUD / PROBE | ベース空間3案の独立比較

作成: 2026-11-07 / ブランチ: `study/space-background-compare-20261107`

## 目的
同じFoundation v0.3の一人称視点・同じ探索信号・同じ現在位置で、ベース空間だけを比較する。
世界観や最終表現はこの研究で確定しない。

## 比較モード
1. ほぼ空: 現行`ProceduralSkyMaterial`。変更前と同一。
2. 薄い情報空間: 上下の空の近似グラデーション＋ごく薄い霧状の帯＋微光点＋細い情報線。
3. 遠景構造物: 2＋方角に固定された淡い円環と縦線の情報構造。

## 操作
- 航行画面で 1/2/3 キー: 3モードを直接選択
- 上部の「空間」ボタン: 次のモードへ切替
- 位置・速度・向き・敵・信号・施設・セーブは切替時に変更しない
- モードの選択自体はセーブされず、起動時は現行相当の「ほぼ空」に戻る

## 実装
- 新規: `godot-foundation/visuals/space_sky.gdshader` — Sky shader。TIME不使用、方向（EYEDIR）で固定背景を生成。
- 変更: `godot-foundation/ui/main.gd` — 比較専用の背景モード、切替ボタンとキー入力。
- `main`、旧`godot/`、旧HTML`index.html`、Foundationのコアゲーム処理は変更していない。
- モード1は元のSkyMaterialのまま。モード2/3のみShaderMaterialを使用する。

## 現時点の検証状態
- リポジトリのコード読解に基づく試作であり、この環境にはGodot実行ファイルがない。
- Godotによる起動・GPU描画の実測検証は**未実施**。
- 比較の視覚研究として、独立HTML Canvas 2Dの操作模型も作成し、Chromiumで切替・前後移動・自動前進・位置リセット・画面表示を確認。HTML版はGodotの描画を完全再現するものではない。

## Godotでの確認項目
1. ブランチを独立worktree/cloneで開き、Godot 4.7.2で`godot-foundation/project.godot`をF5実行。
2. モード1/2/3を同じ位置で切り替え、信号の可読性・空の明るさ・構造の主張具合を比較。
3. 旋回時に線/構造が不自然に追尾しないか確認。
4. 旧システムの戦闘・施設・保存へ副作用がないか、既存testsを実行。
5. 空間構成の好みと負荷を記録してから、密度・線の強さを調整。

比較・試作上の候補であり、採否・世界観の確定ではない。

## 2026-11-07 追加研究：背景色と下方情報層

今回の範囲はベース色・下方ノイズ・流れる光。UI構成、遠景構造物の再設計、ゲーム処理は変更しない。

### 比較できる項目
- 4/5/6: 黒・暗青・暗青緑（全空間モードで独立）
- N: 下方ノイズ OFF → 弱 → 中 → OFF
- F: 下方の光の流れ OFF → 弱 → 中 → OFF
- 1/2/3: 従来の背景密度モード。比較のため維持
- 初期値: 黒、ノイズ弱、流れ弱。背景密度モードは従来どおり1（ほぼ空）で起動

### Godot実装の追加
- `godot-foundation/visuals/data_ground.gdshader`: 世界座標に固定した粒状ノイズと走る信号を描く。
- `godot-foundation/ui/main.gd`: 透明で衝突のないPlaneMeshをカメラ下方に置き、位置だけ追従させる。World座標で模様を評価するため、カメラ移動中にも背景の柄は貼り付かない。
- 既存の空のMaterial、比較用Sky shaderの色を同じキーで切替。既存の探索対象・攻撃処理・保存処理は対象外。
- 平面の描画を使っているが、プレイヤーの歩ける地面を追加したわけではない。
